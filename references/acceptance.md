# 阶段 6：验收

验收分四层，每层都必须给**数字**，不能给「看起来对」。
所有检查脚本失败一律 `sys.exit(1)`，方便串在一条命令里。

## 第一层：几何自检

| 检查 | 判据 | 备注 |
|---|---|---|
| 总装外形 vs 官方/图纸 | 偏差 0.000 mm | 三个方向都查，不查最长边 |
| 分解态两两干涉 | 严格 0 mm³ | 分解后零件不该再接触 |
| 装配态最大搭接 | 小于阈值（设备类 20,000 mm³） | 允许钣金贴合，不允许插入 |
| 关键间隙 | > 0 | 例如电源与主板托盘、风扇与硬盘笼 |
| 刚体平移不变性 | 体积与包围盒边长与原值一致 | 验证分解只是平移 |

阈值要写进脚本注释，说明为什么是这个数，否则下一次改模型无法判断放宽是否合理。

## 第二层：页面探针（无头浏览器）

| 检查项 | 方法 | 判据 |
|---|---|---|
| 零件数 | 数零件树条目 | 与 manifest 一致 |
| 拾取 | 屏幕网格 3×3 点射线拾取 | 9/9 命中 |
| 分解 | 拉滑块到 100%，量零件像素数 | 明显增加 |
| 单件高亮 | 点一件，量其余零件透明度 | 0.17 左右，且**位置不变** |
| 剖切 | 剖后量模型像素 | 减少但**不得低于原 20%**（防切过头） |
| 剖切诊断 | `stageApi.clipReport()` | 分解 100% 且未剖切时，**全部零件 `min > 0`** |
| 线框 | `getWireframe()` | 返回 true |
| 重置 | 重置后读状态 | 分解/剖切/线框全部归零 |
| 报错 | 收 `pageerror` | 空 |
| 布局 | 面板内容高 vs 可视高 | 内容不得超出 |

### 像素计数法

用 canvas 2D 逐像素比对背景色（本项目 `#0e1319`），RGB 差值和 > 26 计为模型像素。
比截图找亮像素可靠，不会被片名、读数、网格污染。

量构图**不要用截图**：用 `stageApi.screenBounds()` 返回所有真实角点投影后的 NDC 包围盒。

### 最重要的一条

凡是「前端算一份、GPU 再算一份」的几何效果（剖切、透明度、雾、线框），
**验收必须落在 GPU 真正消费的参数上**（`plane.constant`、材质属性），
不能只看前端自己的判据。

本项目吃过这个亏：JS 侧 `clipKeeps()` 在 `clip=0` 时直接放行，
而 GPU 用的平面常数停在分解态追不到的位置，结果 11 个零件被静默切掉，
取景、探针、「像素有没有减少」三项检查全部通过。

## 第三层：工程图检查

PDF 没有文本层，`pdftotext` 提取不到字，只能栅格化后用图像分析：

- 渲染：`pypdfium2`，`page.render(scale=300/72).to_pil()`
  （`qlmanage` 被沙箱拦，`sips` 会降采样）
- 检查：逐像素扫长直线（视图框、标注线）+ 网格连通域找文字团块
- 看三件事：尺寸线是否出图框、文字是否被切、视图是否居中

## 第四层：部署校验

1. 本地与线上**比字节**：`curl` 下载后 `md5` 与本地文件一致
2. **必须带随机参数请求**（`?v=$(date +%s)`），CDN 有缓存，不然比的是旧文件
3. 关键控件计数：`grep -c` 每个控件 id，确认新版特征都在
4. 注意 `curl -F file=@路径` 在文件不存在时**只返回 000 不报错**，路径层级写错会静默失败
