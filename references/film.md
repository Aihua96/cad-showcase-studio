# 阶段 5：讲解影片

## 先定分镜，再配音

六幕结构，适用范围最广（机架设备、机械、建筑、桥梁都能套）：

| 幕 | 内容 | 时长参考 |
|---|---|---|
| 1 片头 | 对象全景 + 一句定位 | 2–3 s |
| 2 装配态 | 「装好是什么样」，正面/等轴 | 4–6 s |
| 3 分解 | 从 0 到 100% 的连续分解 | 6–8 s |
| 4 单件细节 | 点亮 2–3 个代表件，其余淡化 | 8–10 s |
| 5 剖面 | 剖切推进，露出内部路径/构造 | 6–8 s |
| 6 收尾 | 数据卡 + 一句话结论 | 3–4 s |

**时间轴必须由配音的真实起句决定，不能先定时长再配音。**
做法：合成配音 → 检测每句起始时间 → `const T = { s1: 0, s2: 2.33, ... }` 严格取起句 →
场景动画挂在这些点上。改一个字重录，整条时间轴自动跟着走。

## 逐帧抓图，不要逐帧重导 STEP

给展示页舞台暴露一个 `stageApi`（`setExplode` / `orbitTo` / `setClip` / `view`），
用 puppeteer 逐帧设定状态后抓图，ffmpeg 合成。**不要为每一帧重新跑 CAD 导出**，
那是数量级更慢的做法。

三条必须遵守：

1. **先探帧**：`--probe N` 先测单帧耗时再定总帧数。软件渲染实测
   5.4 s/帧（1600×900、51 万面）。30 秒 30 fps = 900 帧，那是 80 分钟，不可接受，
   实际要降到 12–15 fps 或分段渲染。
2. **动画按 dt 归一**：`alpha = 1 − exp(−dt / 0.1)`。固定系数 lerp 在个位数帧率下永远收敛不了，
   表现为镜头停在半路（实测偏 78 px）。
3. **透视下视觉重心偏上**（顶面离相机近被放大），构图时 `target.y += 包围盒高 × 0.045`。

抓图环境的坑：本机 Chrome 自身沙箱初始化失败，要包装 `--no-sandbox --disable-crashpad`，
且命令要关外层沙箱运行。`puppeteer-core` 装在
`~/.workbuddy/binaries/node/workspace`；**ESM 不认 NODE_PATH**，要用 `createRequire`
从该目录解析。

## 合成

```bash
ffmpeg -framerate 30 -i frames/%05d.png -c:v libx264 -pix_fmt yuv420p -crf 18 out.mp4
```

- 时长与配音差 0.5 s 以上会明显对不上口型节奏，必须重排
- 配乐 drop 点跟着分解开始的那一帧，不要按固定秒数写死
- 全片检查：`om check` 0 errors、`om qa` 无「缓慢推近」误报（分清「读图停留」与真死帧）

## 配音

### 中文 TTS 的读音问题

系统 `say` 在技术词上不可靠，实测三处必错：

| 文本 | 实际读法 | 修法 |
|---|---|---|
| 长出来的样子 | cháng（应为 zhǎng） | 用克隆 TTS 按上下文合成，不要用 say |
| H100 | 「H 一百」 | 注音文本写「H 一零零」 |
| AI | 被压进 180 ms，几乎吞掉 | 注音文本写「A I」 |

**`say "H100"` 与 `say "H一百"` 输出逐字节相同** —— 这是判断它是否认字最直接的方法。

### 客观验证三个手段

1. **自相关测 F0**：限制 90–400 Hz，加跨帧连续性择优。多音字读错时 F0 会明显上扬
   （「长」读 cháng：140 → 330 Hz）。耳朵听不出，波形能看出。
2. **同文本合成两次比 md5**：判断是否命中缓存、参数是否真的生效。
3. **算字数/秒**：判断有没有漏词。中文正常 4.2–5.1 字/秒；某句只有 2.7 字/秒说明
   TTS 在拖长音，不是漏词。

### 克隆配音

VoiceStudio（OmniVoice）本地服务 `127.0.0.1:3900`：

- `POST /generate`：multipart，`ref_audio` + `ref_text` 零样本克隆，**每句约 78 s**（MPS）
- `POST /pronunciation`：注音
- `/transcribe` 需要额外 ASR 模型，通常没装

流程：逐句合成 → 裁静音 → 归一化 → 按 0.25 s 间隔拼接 → 算新时间轴 → 回写页面。
**合成前先备份原旁白**，中途换路线才不会丢。

## 一个禁令

页面一旦改成「读配音文件」，就**不要再跑 om 自带的配音命令**（`om voice`），
它默认用 `say` 重新合成，会覆盖掉克隆音。

## 出片前必须做的两件事

1. **无头实测前端**：拉滑块、点零件树、切视角、射线拾取、逐张截图、收 `pageerror`。
   超时分支要把 `pageerror` 打出来，否则只看到一个 TimeoutError，不知道错在哪。
2. **验证素材比例**：素材若按 3:2 出图、放进 16:9 画布用 `cover`，会切掉 30% 高度。
   按目标画布比例重新渲染，别靠 `object-fit` 硬塞。

## 文字动画的一个硬坑

CSS `transform: translateY(110%)` 会被 GSAP 读成**像素**（`y: 116.15`），
之后 `fromTo(yPercent)` 清不掉，`overflow: hidden` 会把标题全挡住，且不报错。

在建时间轴之前强制复位：

```js
gsap.set('.line > span', { yPercent: 110, y: 0 });
```
